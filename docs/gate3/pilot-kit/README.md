# TTX pilot kit

Printable handouts for the Gate 3 pilot ([pilot plan](../ttx-pilot-plan.md)). Print them the day before. Each one fits on one or two A4 pages.

| Handout | Who | Copies |
|---|---|---|
| [Installation check](installation-check.md) | Observer, at 08:30 | 1 per exercise machine |
| [Seat card](seat-card.md) | Blue and Red players | 1 per player |
| [White-cell run sheet](white-cell-run-sheet.md) | Exercise director, assistant umpire | 1 each |
| [Observer's log](observer-log.md) | Observer | 3–4 pages |
| [Questionnaire](questionnaire.md) | Every participant except the observer | 1 each |

Also have at each seat: the [user manual](../../manuals/user-manual.md) §2–7. Have the [white-cell manual](../../manuals/white-cell-manual.md) at the white cell.

**Afterwards:** the filled-in log and questionnaires go into the pilot report (pilot plan §9), with the exercise record (`.nwsrec`) and the AAR CSV files. They stay with the client.
